> WebCachePoisoning — это продвинутая техника, с помощью которой пользователь использует поведение веб-сервера и кэша, чтобы отправить другим пользователям вредоносный ответ HTTP.

* *Отравление веб-кэша включает в себя два этапа:*
  * Выяснить, как получить ответ от внутреннего сервера, который непреднамеренно содержит какую-то опасную полезную нагрузку. 
  * Убедиться, что ответ кэшируется и в последствии отправляется предполагаемым жертвам.
