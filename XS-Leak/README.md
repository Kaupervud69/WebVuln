# XS-Leak

> `Cross-Site Leaks (XS-Leaks)` — это атаки по сторонним каналам, позволяющие злоумышленникам извлекать конфиденциальную информацию из целевого источника без чтения тела ответа. Они используют поведение браузера, временные различия и наблюдаемые побочные эффекты вместо традиционного хищения данных через XSS.

## Методология

### Примитивы атак

В отличие от классических атак CORS или XSS, XS-Leak полагаются на наблюдаемое поведение браузера:

| Примитив | Что можно узнать |
|---|---|
| Время (Timing) | Размер / сложность ресурса |
| Количество фреймов (Frame count) | Различия в содержимом |
| Ошибки (Errors) | Решения системы контроля доступа |
| Кеш (Cache) | Предыдущие посещения |
| Навигация (Navigation) | Состояние аутентификации |
| Рендеринг (Rendering) | Длина текста |



### XS-Search

Атаки **XS-Search** используют поисковые системы на основе запросов для утечки информации о пользователе. Измеряя побочные эффекты поискового запроса (например, время ответа, количество фреймов или события ошибок), злоумышленник может определить, вернул ли поиск результаты или нет.

Этот **булев оракул** можно использовать для перебора конфиденциальных данных посимвольно.

**Примеры:**
- Открытие 50 вкладок и использование разницы во времени от нарушения CSP в iframe на странице результатов поиска для перебора флага по символам.


## Межсайтовые оракулы

### Атаки по времени (Timing Attacks)

При атаке по времени злоумышленник пытается получить конфиденциальную информацию, наблюдая за тем, сколько времени требуется системе для ответа на определённые запросы. Он развёртывает тщательно разработанные скрипты в целевом приложении для выполнения вызовов API, отправки AJAX-запросов или инициирования взаимодействий CORS. Измеряя и сравнивая время ответа на эти операции, злоумышленник может сделать выводы о внутреннем поведении системы, процессах проверки данных или механизмах безопасности.



### Подсчёт фреймов (Frame Counting)

Если страница загружает разное количество iframe в зависимости от состояния пользователя (например, результаты поиска), злоумышленник может подсчитать их, чтобы сделать выводы о данных.

**Пример кода:**
```javascript
// Получаем ссылку на окно
var win = window.open('https://example.org');

// Ждём загрузки страницы
setTimeout(() => {
  // Читаем количество загруженных iframe
  console.log("%d iframes detected", win.length);
}, 2000);
```



### Зондирование кеша (Cache Probing)

При атаке зондированием кеша вредоносный сайт пытается определить, сохранён ли конкретный ресурс с целевого сайта в кеше браузера жертвы.

Злоумышленник заставляет браузер запросить ресурс (например, изображение, скрипт или конечную точку), который может быть закеширован только в том случае, если пользователь аутентифицирован или ранее посещал определённую страницу. Измеряя скорость загрузки ресурса или наблюдая различия в поведении между кешированным и некешированным ответом, злоумышленник может получить конфиденциальную информацию.



### Известные оракулы

| Название | Описание |
|---|---|
| Cache Leak (CORS) | Обнаружение ресурсов, загруженных страницей. Кеш удаляется с ошибкой CORS. |
| Cache Leak (POST) | Обнаружение ресурсов, загруженных страницей. Кеш удаляется с POST-запросом. |
| ContentDocument X-Frame Leak | Обнаружение X-Frame-Options с помощью ContentDocument. |
| COOP Leak | Обнаружение заголовка Cross-Origin-Opener-Policy через всплывающее окно. |
| CORB Leak | Обнаружение X-Content-Type-Options в сочетании с конкретным типом контента через CORB. |
| CORP Leak | Обнаружение заголовка Cross-Origin-Resource-Policy через fetch. |
| CORS Error Leak | Утечка целевого URL перенаправления через ошибку CORS. |
| CSP Directive Leak | Обнаружение директив CSP через атрибут iframe CSP. |
| CSP Redirect Detection | Обнаружение межсайтовых перенаправлений через событие нарушения CSP. |
| CSP Violation Leak | Утечка цели межсайтового перенаправления через событие нарушения CSP. |
| CSS Property Leak | Утечка CSS-правил через getComputedStyle. |
| Disk cache grooming | Использование дискового кеша для утечки данных. |
| Download Detection | Обнаружение загрузок (заголовок Content-Disposition). |
| Duration Redirect Leak | Обнаружение межсайтовых перенаправлений по продолжительности. |
| ETag header length | Определение размера тела ответа по длине заголовка ETag. |
| Event Handler Leak (Object) | Обнаружение ошибок через onload/onerror с объектом. |
| Event Handler Leak (Script) | Обнаружение ошибок через onload/onerror со скриптом. |
| Event Handler Leak (Stylesheet) | Обнаружение ошибок через onload/onerror с таблицей стилей. |
| Fetch Redirect Leak | Обнаружение HTTP-перенаправлений через Fetch API. |
| Frame Count Leak | Обнаружение количества iframe на странице. |
| History Length Leak | Обнаружение JavaScript-перенаправлений через History API. |
| Id Attribute Leak | Утечка атрибута id фокусируемых HTML-элементов через onblur. |
| Max Redirect Leak | Обнаружение серверного перенаправления через превышение лимита редиректов. |
| Media Dimensions Leak | Утечка размеров изображений или видео. |
| Media Duration Leak | Утечка длительности аудио или видео. |
| MediaError Leak | Обнаружение кодов состояния через сообщение MediaError. |
| Payment API Leak | Обнаружение использования Payment API в другой вкладке. |
| Performance API CORP Leak | Обнаружение заголовка Cross-Origin-Resource-Policy через Performance API. |
| Performance API Download Detection | Обнаружение загрузок (заголовок Content-Disposition) через Performance API. |
| Performance API Empty Page Leak | Обнаружение пустых ответов через Performance API. |
| Performance API Error Leak | Обнаружение ошибок через Performance API. |
| Performance API X-Frame Leak | Обнаружение X-Frame-Options через Performance API. |
| Performance API XSS Auditor Leak | Обнаружение скриптов/обработчиков событий на странице через Performance API. |
| Redirect Start Leak | Обнаружение межсайтовых HTTP-перенаправлений через время redirectStart. |
| Request Merging Error Leak | Обнаружение ошибок через слияние запросов. |
| SRI Error Leak | Утечка длины содержимого через ошибку SRI. |
| Style Reload Error Leak | Обнаружение ошибок через баг перезагрузки стилей. |
| URL Max Length Leak | Обнаружение серверного перенаправления через превышение максимальной длины URL. |
| WebSocket Leak (FF) | Обнаружение количества WebSocket на странице через исчерпание лимита сокетов (Firefox). |
| WebSocket Leak (GC) | Обнаружение количества WebSocket на странице через исчерпание лимита сокетов. |
