# Zip Slip

> Уязвимость Zip Slip эксплуатируется с помощью специально созданного архива, содержащего имена файлов с обходом директорий (например, `../../shell.php`). Уязвимость Zip Slip может затрагивать множество форматов архивов, включая tar, jar, war, cpio, apk, rar и 7z. Злоумышленник может перезаписать исполняемые файлы и либо вызвать их удалённо, либо дождаться, пока система или пользователь вызовут их, что приведёт к удалённому выполнению команд на машине жертвы.

## Методология

Уязвимость Zip Slip — это критическая проблема безопасности, связанная с обработкой архивных файлов, таких как ZIP, TAR или других форматов сжатых файлов. Эта уязвимость позволяет злоумышленнику записывать произвольные файлы за пределы целевой директории распаковки, что потенциально может привести к перезаписи критических системных файлов, выполнению вредоносного кода или получению несанкционированного доступа к конфиденциальной информации.

### Пример

Предположим, злоумышленник создаёт ZIP-файл со следующей структурой:

```
malicious.zip
  ├── ../../../../etc/passwd
  ├── ../../../../usr/local/bin/malicious_script.sh
```

Когда уязвимое приложение распаковывает `malicious.zip`, файлы записываются в `/etc/passwd` и `/usr/local/bin/malicious_script.sh` вместо того, чтобы оставаться в директории распаковки. Это может иметь серьёзные последствия, такие как повреждение системных файлов или выполнение вредоносных скриптов.

### Примеры команд

**Использование evilarc (ptoomey3/evilarc):**

```bash
python evilarc.py shell.php -o unix -f shell.zip -p var/www/html/ -d 15
```

**Создание ZIP-архива, содержащего символическую ссылку:**

```bash
ln -s ../../../index.php symindex.txt
zip --symlinks test.zip symindex.txt
```

### Что происходит под капотом?

1. Приложение получает архив (ZIP, TAR и т.д.) от пользователя.
2. Приложение распаковывает архив без проверки имён файлов.
3. Внутри архива файл называется `../../etc/passwd`.
4. При распаковке система "послушно" идёт на две папки вверх и записывает файл в `/etc/passwd`.
5. Системный файл перезаписан — либо повреждена система, либо внедрён вредоносный код.

### Простая аналогия

Представь, что ты даёшь курьеру коробку с инструкцией: "Отнеси содержимое в комнату 5". Но внутри коробки лежит записка: "На самом деле отнеси это в комнату 10 и выйди через чёрный ход". Если курьер не проверит инструкцию внутри — он выполнит то, что написано в записке, даже если это противоречит его заданию.

Zip Slip работает так же — приложение доверяет именам файлов внутри архива, не проверяя, куда они на самом деле ведут.
